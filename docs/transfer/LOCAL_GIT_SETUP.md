# QPLAB — Local Git setup

This repository was cloned locally on Windows to enable byte-preserving transfer of original MT5 source files.

Expected local clone:
C:\\Users\\qrpic\\QPLAB

After installing Git for Windows, run from PowerShell:

git --version
cd C:\\Users\\qrpic\\QPLAB
git remote -v

The original five MT5 source files must be verified by SHA-256 before commit.
