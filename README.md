# QPLAB

Open-source scientific laboratory for the study of structural conservation and physiological dynamics in complex dynamical systems.

## Status

This repository is being established as the public software and research repository for QPLAB. The initial phase preserves the existing scientific record and prepares the project for reproducible open-source development.

## Scope

QPLAB research materials will be organized into:

- scientific documentation
- experimental protocols and preregistrations
- source code
- experiments and analyses
- public datasets and examples
- reproducibility tests
- historical archives

Historical experimental results, including negative or falsified results, will be preserved without retroactive modification.

## Reproducibility principle

Scientific claims, hypotheses, protocols, code, data, and results must remain traceable to their corresponding versions and experimental records.
